# 🏠 House Price Prediction – Muzaffarpur, Bihar  An AI-powered house/property valuation web application that estimates the value of a property in **Muzaffarpur, Bihar** based on important property characteristics.  The machine learning model was developed and trained using **PyTorch in JupyterLab** and exported to **ONNX format** for integration with the web application.  ## 📌 Project Overview  This project combines **Machine Learning and Web Development** to create an interactive property valuation system.  Users can enter or select different property details, and the application uses the trained machine learning model to calculate an estimated property value.  ### The application considers:  - 📍 **Locality** – Different areas/locality tiers - 📐 **House Size** – Property size in square feet - 🛏️ **Number of Bedrooms (BHK)** - 🏢 **Total Floors** - 🛣️ **Road-side Property** – Whether the property is located beside a road or not  The combination of these factors is used to generate the estimated property value.  ---  ## ✨ Features  - 🏠 AI-powered house price prediction - 📍 Locality-based valuation - 📐 House size input in square feet - 🛏️ BHK/bedroom selection - 🏢 Total floor selection - 🛣️ Road-side property consideration - 💰 Estimated property value - 🤖 PyTorch-trained machine learning model - ⚡ ONNX model integration - 🌐 Interactive web interface  ---  ## 🧠 Machine Learning  The prediction model was developed using **PyTorch** in **JupyterLab**.  ### Model Development Workflow  ```text Property Dataset        ↓ Data Preprocessing        ↓ Feature Selection        ↓ PyTorch Model        ↓ Model Training        ↓ Model Evaluation        ↓ ONNX Model        ↓ Web Application        ↓ Estimated Property Value
